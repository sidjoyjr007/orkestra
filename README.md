# Orkestra

A universal agent orchestration framework for Python.
Built with scalability, modularity, and enterprise resilience in mind.

## Features
- **Semantic Tool Routing**: Dynamically load tools for agents at runtime using ChromaDB.
- **Zero-Dependency Event Bus**: Native asynchronous hooks for complete observability.
- **Agent Checkpointing**: Pause, serialize, and resume agents backed by PostgreSQL.
- **MCP Native**: First-class support for Model Context Protocol.
